# Portfolio summary

**Web Scraping & NLP: Exploratory Media Content Analysis**

Python, Selenium, SQLite, pandas, matplotlib, spaCy (optional), Ollama / Llama 3.2 (optional).

This project explores a pipeline from responsible collection of public article metadata to descriptive analysis and experimental LLM-assisted text coding. It emphasizes reproducibility, data quality, transparent limitations and human validation rather than presenting model labels as objective facts.

**Skills demonstrated:** data collection workflow design, relational storage, exploratory data analysis, text preprocessing, named-entity recognition, prompt engineering, JSON validation and research-methodology awareness.
